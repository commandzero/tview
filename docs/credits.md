# Credits

Tview is a Rust rewrite of [Tabview](https://github.com/Tabviewer/tabview).

Scott Hansen <tech@firecat53.net> published Tabview, based on
[code](http://www.amk.ca/files/simple/tabview.txt) contributed by A.M. Kuchling
<amk@amk.ca>.

Other contributors:

- Matus Gura <matus.gura@gmail.com>
- Nathan Typanski <ntypanski@gmail.com>
- Sébastien Celles <s.celles@gmail.com>
- Yuri D'Elia <wavexx@thregr.org>

The project retains the upstream [MIT license](../LICENSE.txt). Upstream Tabview
described its future maintenance as sporadic and recommended
[Visidata](https://github.com/saulpw/visidata) for a fuller spreadsheet
application.
